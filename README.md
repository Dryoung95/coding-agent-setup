# 配置中心（镜像）

沐曦 Coding Agent 实战营第一课配置中心的静态镜像，与课程仓库里的
`lesson-01-coding-agent/lab/index.html` 同一份文件。

页面是单文件、零外部依赖，所有拼接都在浏览器本地完成，不上传任何数据。

线上地址：<https://dryoung95.github.io/coding-agent-setup/>

课程仓库：<https://www.gitlink.org.cn/Dryoung/MetaX-Coding-Agent-Bootcamp>

## 更新方式

用课程仓库里的新版本覆盖 `index.html`，提交推送到 `main` 即可，Pages 会自动重新构建。
