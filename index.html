STEP 01 / GET TOKEN

先拿到属于你的 Token

没有 Token，后面全白搭。这一步只需要登录并生成一个访问令牌。

只有两件事要做：① 登录模力方舟 → ② 生成一个访问令牌。令牌生成后复制好，下一步就要用到。
1 — 登录

打开模力方舟并登录

用你的账号登录模力方舟控制台。登录后即可在设置里管理访问令牌。

打开模力方舟 ↗

2 — 生成令牌

工作台 → 设置 → 访问令牌

点击「新建令牌」，复制生成的字符串。它只会完整显示一次，请立刻粘贴到下一步的输入框里，或先存到本地备忘。

直达访问令牌页面 ↗

Token 形如一长串字母数字。不要把它贴进任何聊天窗口、公开仓库或论坛——它等同于你的钱包密码。

STEP 02 / INSTALL CLI

装一个编码 Agent 命令行

三种任选其一即可，不确定选哪个就选 Codex。已按你的系统高亮对应命令，点一下命令即可复制。

npm 方式需要先装 Node.js 18+。完全没用过命令行的话，去 nodejs.org 下载 LTS 安装包，一路「下一步」装完，重启终端再执行下面的命令。原生脚本方式则不需要 Node。
◎npm · Node 18+

STEP 03 / DESKTOP BRIDGE

装 CC Switch（关键一步）

CC Switch 是本地桌面配置桥。必须先装它，第 4 步的「一键导入」才有接收方。没装就点导入，浏览器会没有反应。

顺序别搞反。很多人卡住都是因为先点了「生成并导入配置」，但电脑上还没有 CC Switch。正确顺序：装 CLI → 装 CC Switch → 生成配置 → 导入。

下载安装包，双击一路「下一步」。支持 Windows 10 / 11。

这枚令牌在本页怎么处理
  1. 页面上不会出现完整令牌。输入框是密码态，右侧预览里的形状是 sk-••••••••3XYZ，后四位只用来核对是哪一枚。截图到这里是安全的。
  2. 点「复制」才把完整值写进剪贴板，页面上不渲染。复制后直接粘进配置文件，粘完再截终端图。
  3. 已经泄出去了：去 访问令牌页 删掉那一枚、重新生成一枚，旧令牌当场失效。作业进度不受影响。

没有装 CC Switch、或弹窗被拦截时，可点击右侧「复制配置」手动写入文件，文件路径见右侧说明。

卡住了？对照报错找答案

      

        
点了「生成并导入配置」，浏览器一点反应都没有

          
    
            
  • 99% 是本机还没装 CC Switch，或者装了但没启动过。去第 3 步装好并启动一次。
    • 
            
  • 或者浏览器把协议跳转拦截了。看地址栏右侧是否有被拦截的图标，手动允许「打开 CC Switch」。
    • 
            
  • macOS 若提示无法打开，去「系统设置 → 隐私与安全性」放行一次。
    • 
            
  • 协议没注册成功时：Windows 重装一次安装包，或检查注册表 HKEY_CLASSES_ROOT\ccswitch；macOS 执行 open -a "CC Switch" --args --register-protocol。
    • 
            
  • 兜底方案：点「复制配置」，按右侧路径提示手动写入文件。
    • 
          

        


        
报错 401 Unauthorized / invalid api key

          
    
            
  • Token 复制时多带了空格或换行。删掉重新粘贴一次，注意别把「Bearer」前缀也复制进去。
    • 
            
  • Token 被删除或过期了，回 访问令牌页重新生成一个。
    • 
            
  • 用默认的免费体验令牌时可能有每日次数限制，次数用完也会报错。
    • 
          

        


        
报错 model not found / 404 / invalid model

          
    
            
  • 模型名与平台不一致。到模力方舟控制台的模型列表里原样复制模型 ID。
    • 
            
  • 带 -Preview 后缀的模型属于预览版，可能已下线或改名为正式版，建议换成不带 Preview 的型号。
    • 
            
  • 选了资源包里不包含的模型。资源包只覆盖它列出的那些模型，换一个包内模型即可。
    • 
            
  • 回到第 4 步，模型下拉选「其他 —— 手动输入模型 ID」，粘贴准确名称重新导入。
    • 
          

        


        
改了配置，但终端里还是老样子 / 完全没变化

          
    
            
  • 彻底关掉终端再重新打开。仅切标签页不算，最好整个退出进程。
    • 
            
  • 确认 CC Switch 里对应的供应商卡片是「当前启用」状态（通常有高亮边框）。
    • 
            
  • Claude Code 一般支持热加载；Codex / OpenCode 通常需要重启。
    • 
            
  • 检查是否同时存在多个配置来源冲突（比如你既改了 shell 里的环境变量，又用 CC Switch 导入了一份）。
    • 
          

        


        
提示 command not found / 不是内部或外部命令

          
    
            
  • 大概率是装完后没有重开终端。关掉终端重新开一个再试。
    • 
            
  • npm 全局目录没进 PATH。执行 npm config get prefix 看路径，把它加进系统环境变量 PATH。
    • 
            
  • Windows 上如果是用 nvm 装的 Node，重启一次电脑通常就能解决。
    • 
          

        


        
连接超时 / ETIMEDOUT / 一直卡住不动

          
    
            
  • 检查本机网络能否访问 moark.com（浏览器打开试试）。
    • 
            
  • 公司网络 / 代理可能拦截了 API 域名，换一个网络环境试试。
    • 
            
  • 确认请求地址填对了：Codex 用 https://moark.com/v1，Claude Code 用 https://moark.com/anthropic，OpenCode 用 https://ai.gitee.com/v1，三者不通用。
    • 
          

        


        
把 Token 填进这个网页，安全吗？

          
    
            
  • 页面本身不联网上传任何东西，所有拼接都在你浏览器本地完成，可以断网使用（会少了图标等资源）。
    • 
            
  • 但要注意：「一键导入」生成的 ccswitch:// 链接里明文包含你的 Token，它会进入浏览器历史记录。请不要复制这个链接发给别人、也不要发到公开渠道。
    • 
            
  • 如果是团队共享，推荐的做法是：链接里不放 Token，让每个人自己填；或者直接在 CC Switch 里手动「添加供应商」，完全不走链接。
